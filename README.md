# HIT140 Assessment 2 – FIFA World Cup 2026

## Project Overview
This repository contains the Python code, datasets, visualisations, and supporting materials for HIT140 Assessment 2.

The project analyses FIFA World Cup 2026 data using four distinct analytic tasks.

## Analytic Tasks
1. Passing Performance
2. Discipline / Cards
3. Goalkeeper Performance
4. Attacking Efficiency

## Data Sources
- FIFA Official Website
- The Stats Don't Lie
- FBref
