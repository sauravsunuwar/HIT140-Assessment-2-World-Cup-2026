# HIT140 Assessment 2 – FIFA World Cup 2026 Data Analysis

## Project Overview

This repository contains the group work for **HIT140 – Foundations of Data Science, Assessment 2**.

The project analyses FIFA World Cup 2026 match data using Python and statistical methods. The group investigates different aspects of team performance through four individual analytic tasks.

The analysis includes data collection, data cleaning and preparation, random sampling, descriptive statistics, confidence intervals, hypothesis testing, data visualisation, and interpretation of results.

## Analytic Tasks

The project is divided into four main areas:

### 1. Attacking Efficiency
This analysis investigates attacking performance during FIFA World Cup 2026 matches.

📁 Folder: `Attacking_Efficiency`

### 2. Discipline / Cards Analysis
This analysis investigates disciplinary performance using match statistics related to cards and other relevant disciplinary measures.

📁 Folder: `Discipline_Cards_Analysis`

### 3. Passing Accuracy
This analysis investigates whether winning teams have significantly higher mean passing accuracy than losing teams in decisive FIFA World Cup 2026 matches.

Passing accuracy is calculated as:

**Passing Accuracy (%) = (Completed Passes / Total Passes) × 100**

For the statistical analysis, the difference between the two teams in each decisive match is calculated as:

**Difference = Winner Passing Accuracy − Loser Passing Accuracy**

📁 Folder: `Passing_accuracy`

### 4. Goalkeeper Performance
This analysis investigates goalkeeper performance during FIFA World Cup 2026 matches using relevant goalkeeper statistics.

📁 Folder: `goalkeeper`

## Data Analysis Process

The general workflow used throughout the project was:

1. Collect relevant FIFA World Cup 2026 match data.
2. Import and organise the data using Python.
3. Clean the dataset and check for missing, duplicate, or invalid observations.
4. Create variables required for each research question.
5. Apply appropriate sampling methods.
6. Calculate descriptive statistics.
7. Construct confidence intervals.
8. Conduct appropriate inferential statistical tests.
9. Create visualisations.
10. Interpret the results in relation to each research question.
